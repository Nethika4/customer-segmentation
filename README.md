# Customer Segmentation Project

This project demonstrates customer segmentation using Python and scikit-learn.
It generates a synthetic customer dataset, performs clustering using K-Means,
and visualizes segment characteristics to help derive actionable customer insights.

## Key Features

- Synthetic customer dataset generation
- Clustering with K-Means
- Purchase pattern and demographic analysis
- Segment profiling and visualization

## Files

- `customer_segmentation.ipynb` - interactive analysis notebook
- `requirements.txt` - Python dependencies

## Setup

1. Create a Python environment:
   ```bash
   python -m venv venv
   .\venv\Scripts\Activate.ps1
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Open `customer_segmentation.ipynb` in VS Code or Jupyter.

## Notes

- The notebook includes data generation, clustering, and segment visualization.
- You can replace the synthetic dataset with your own customer data as needed.
